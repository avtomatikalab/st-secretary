# СТ-Секретарь

Открытая система для секретариата и судей соревнований по спортивному туризму: заявки, допуск,
жеребьёвка, протоколы этапов, подсчёт результатов, ранг и разряды, дипломы, справки, отчёты,
онлайн-табло. Работает и с интернетом, и без него.

Проект некоммерческий, код открыт под лицензией [AGPL-3.0](LICENSE).

> **Статус:** этап 1 — помощник секретаря. Готовы ядро расчётов (ранг, нормативы, места, ПСР,
> спелео, допуск) и программа в браузере: карточка соревнования и проверка предзаявок. Остальные
> шаги работы секретариата уже видны в меню с описанием того, что в них будет.

## Зачем

На соревнованиях много ценных часов уходит на монотонную работу с бумагами и таблицами, а ошибки
в документах дорого обходятся: неверный код дисциплины в протоколе, неправильно посчитанная сумма
баллов, разряд не по той строке норм. Система берёт рутину на себя и проверяет всё, что можно
проверить автоматически.

## Принципы

1. **Одна карточка соревнования.** Название, статус, даты, место, судейская коллегия, дисциплины
   вводятся один раз и попадают во все документы. Прошлогодние файлы не копируются.
2. **Справочники из первоисточников.** Коды ВРВС, разрядные нормы (с выбором редакции), требования
   допуска берутся из официальных документов, у каждой таблицы указан источник.
3. **Точные расчёты.** Время и баллы считаются точными дробями, без округлений на промежуточных
   шагах. Спорные методики не угадываются — их выбирают явно в настройках соревнования.
4. **ИИ не участвует в расчётах.** Результаты, места, ранги и разряды — только по правилам и под
   тестами. ИИ в будущем — лишь помощник (разбор заявок из почты, подсказка судье пункта таблицы
   штрафов).
5. **Офлайн прежде всего.** Ноутбук секретариата — главная копия данных, работает без интернета.
   Облако нужно для онлайн-табло и приёма данных от судей, когда есть связь.
6. **Записи судей только добавляются.** Исправление — новая запись со ссылкой на прежнюю: полный
   след для протестов и слияние данных с разных телефонов без конфликтов.
7. **Персональные данные — по минимуму.** В облако уходят только ФИО, команда и результат. Даты
   рождения и паспортные данные остаются на ноутбуке. В репозиторий реальные данные не попадают
   никогда: тесты работают на обезличенных копиях.

Подробнее — [docs/architecture.md](docs/architecture.md), решения — [docs/decisions.md](docs/decisions.md),
план — [docs/roadmap.md](docs/roadmap.md).

## Что уже умеет ядро

| Модуль | Что делает |
|---|---|
| `reference` | Справочники: коды ВРВС, разрядные нормы 2022–2025 и 2026–2029, требования допуска (ПСР, спелео, пешеходные) |
| `qualification` | Разряды: любые написания («б/р», «3ю», «III», «кмс»), старшинство |
| `rank` | Квалификационный ранг вида программы; условие ЕВСК о числе участников и субъектов |
| `norms` | Строка норм по классу и рангу, процент от победителя, выполненный разряд с учётом уровня соревнований и возраста |
| `ranking` | Места: равные результаты, неклассифицированные участники, порядок старта |
| `disciplines.psr` | ПСР: сумма баллов по этапам и турам, места, класс дистанции по табл. 3, технический штраф этапа |
| `disciplines.speleo` | Спелео: время − отсечки + баллы × 15/30 с, снятия с этапов |
| `admission` | Допуск: возраст в календарный год, возрастные группы, минимальный разряд, возраст руководителя |
| `importers.sekretar_xls` | Чтение книг СЕКРЕТАРЬ_ST и итоговых протоколов прошлых лет |
| `competition`, `importers.card_xlsx` | Карточка соревнования: шаблон Excel с выпадающими списками, чтение, проверки |
| `textclean` | Чистка ручного ввода: слитные ФИО, дата в ФИО, форматы дат, пол по отчеству, телефоны |
| `preapp`, `importers.preapp_xlsx`, `exporters.preapp_xlsx` | Предзаявки: чистка, сверка с карточкой, допуск, дубли → сводка Excel для СЕКРЕТАРЬ_ST |
| `commission`, `equipment` | Комиссия по допуску: документы, решения, взносы, перезаявки, проверка снаряжения |
| `results`, `names`, `exporters.awards`, `exporters.judges`, `exporters.final` | Документы по итогам: места по зачётам, склонение ФИО и названия соревнований, дипломы, наклейки, справки, выписки, отчёт |
| `staff`, `money`, `exporters.contracts` | Договоры, акты, табель: дни, ставки, суммы прописью, проверка ИНН/СНИЛС/счёта, шаблоны Word с полями |
| `verify` | Сверка документов (Word, Excel, PDF) с карточкой и между собой: даты, коды ВРВС, ФИО, категории, суммы, табель ↔ договоры и акты |
| `web` | Программа в браузере: все шаги выше; хранение по папкам соревнований |

## Как пользоваться

### Секретарю — программа в браузере

1. Один раз установите [uv](https://docs.astral.sh/uv/getting-started/installation/) — через него
   запускается программа. Скачайте СТ-Секретарь (на GitHub: Code → Download ZIP) и распакуйте.
2. Дважды щёлкните **`СТ-Секретарь.bat`**. При первом запуске скачаются нужные библиотеки (нужен
   интернет, один раз), дальше программа работает без интернета. Пока программа запускается,
   в окне бежит полоска и идут секунды — значит, всё в порядке, надо подождать. Библиотеки ставятся
   не рядом с программой, а в `%LOCALAPPDATA%\st-secretary\venv`: папку программы можно держать
   в облаке (Google Диск, Яндекс Диск), а облако, синхронизируя файлы, мешает их обновлять.
3. Откроется браузер со страницей программы. Чёрное окно — это сама программа: не закрывайте его,
   пока работаете. Само оно не закрывается.
4. Закончили — нажмите «Выключить» вверху страницы (или закройте чёрное окно). Всё сохраняется
   сразу, отдельно сохранять ничего не нужно.

Что уже работает:

- **Соревнования** — список; новое создаётся за минуту или загружается готовая карточка из Excel.
- **Карточка соревнования** — открывается для просмотра; «Редактировать карточку» — обычная форма
  с выпадающими списками и проверкой: ошибка видна у самого поля, введённое не пропадает. Сохраняется в файл Excel — его можно открыть и поправить и
  там (если карточку изменили в Excel, пока была открыта страница, программа не затрёт правки).
- **Предварительные заявки** — файлы команд перетаскиваются на страницу; сразу видны число команд
  и участников, ошибки и то, что нужно проверить, — по командам, рядом телефоны представителей.
  У каждого замечания написано, **почему** оно появилось и **что сделать**.
  Кнопка «Открыть сводку в Excel» — готовые строки для СЕКРЕТАРЬ_ST. Заявки не удаляются: «Убрать»
  переносит файл в папку «Предзаявки\Убранные».
- **Карточка команды** — щелчок по названию команды: заявка, замечания и статус заявки
  («Проверить», «Исправить», «Проверено»). У замечаний «проверить» — кнопка «Проверено». Фильтр
  на странице заявок показывает команды с ошибками, требующие проверки или уже проверенные.
  По заявкам можно идти подряд — «Следующая команда →»; при возврате к списку он открывается
  сразу на той команде, с которой вы работали.
- **Заявка в форме** — «Редактировать заявку» открывает её как таблицу: поля с замечаниями
  обведены, объяснения — под строкой участника; можно добавить или удалить участника. «Сохранить и
  проверить» записывает заявку в файл Excel, проверяет заново и возвращает в карточку команды; прежний
  файл остаётся в «Предзаявки\Прежние версии». Состав, присланный текстом, можно ввести через
  «Заполнить заявку вручную».
- **Комиссия по допуску** — участники из предзаявок; галочки по документам (паспорт, медицинский
  допуск, книжка, ОМС, страховка; по команде — заявка и допуск врача), «Отметить все документы»,
  решения «допустить решением комиссии» / «не допускать» с причиной, номера команд, взносы,
  перезаявки с временем подачи и контролем «за час до старта». Всё сохраняется сразу. Кнопка
  «Открыть в Excel» — протокол комиссии по форме Правил и ведомость взносов.
- **Документы команды** — сканы и фото (паспорта, полисы, справки) в карточке команды; на комиссии —
  «Проверить в одном окне»: документ слева, галочки справа. Хранятся только на этом компьютере, в папке
  «СТ-Секретарь — документы участников» в профиле пользователя — не в облаке и не в папке соревнования.
  Для пробы вместо настоящих сканов — заглушки:
  `uv run --with pillow python tools/make_stub_docs.py "данные/<папка соревнования>"`.
- **Проверка снаряжения** — перечень из Положения (образец ПСР), отметки по участникам и команде,
  штрафные баллы и порог снятия; итог учитывается в допуске и попадает в акт.
- **Награждение и документы по итогам** — места по зачётам из итогового протокола СЕКРЕТАРЬ_ST
  (.xls) или вручную; оценки судейства; тексты отчёта. Одной кнопкой — в Word или Excel, в папку
  «Документы по итогам»: дипломы (у каждого участника свой диплом, его имя первое), наклейки на
  медали, список награждаемых, справки о судействе, справка о составе и квалификации судейской
  коллегии, справка о количестве субъектов РФ, выписки на разряды, отчёт главного судьи. Название,
  даты, место и подписи — из карточки; даты рождения для выписок — из заявок. Перед печатью документ
  можно поправить в Word.
- **Договоры, акты, табель** — табель по дням: судьи из карточки, комендант и рабочие добавляются на
  странице; галочка — рабочий день, суммы считаются сразу по ставкам (должность × категория; образец
  2025 г.). Кнопками — «Табель-наряд.xlsx» (дни и суммы формулами Excel) и договоры с актами: всем одним
  файлом или каждому отдельно. Сумма прописью, «в лице директора …», «в качестве главного судьи 1 категории»,
  срок — по отмеченным дням, поэтому табель, договор и акт не расходятся. Паспорт, ИНН, СНИЛС и счёт
  вводятся один раз и хранятся только на этом компьютере (ИНН, СНИЛС и счёт проверяются по контрольным
  цифрам). Форма договора — своя у заказчика: встроенный шаблон сохраняется в папку соревнования
  («Шаблон договора.docx»), в него переносят текст заказчика с полями `{{ФИО}}`, `{{Сумма прописью}}` и др.;
  для отдельной должности — «Шаблон договора — главный судья.docx».
- **Сверка документов** — программа читает готовые документы (Word, Excel, PDF с текстом) и показывает, что
  расходится с карточкой и между документами: даты не того года (документ сделан из прошлогоднего), чужие
  коды ВРВС, опечатки в названии дисциплины, ФИО и инициалы не как в карточке и заявках, категории судей,
  сумму цифрами и прописью, отметки и суммы в табеле, срок и суммы в договоре и акте, договоры против
  табеля. Документы программы проверяются всегда; протоколы СЕКРЕТАРЬ_ST, договоры заказчика и другие файлы
  перетаскиваются на страницу — программа их только читает и не сохраняет.
- Остальные шаги (стартовые, результаты, табло) — в меню, с описанием того, что в них будет.

Все данные — в папке `данные` рядом с программой, одна папка на соревнование. Страница открывается
только на этом компьютере (адрес `127.0.0.1`), в интернет ничего не отправляется.

### Командная строка

```bash
uv run st-secretary web                                # то же, что двойной щелчок по .bat
uv run st-secretary card-template Карточка.xlsx        # пустая карточка соревнования
uv run st-secretary card-check Карточка.xlsx           # проверить заполненную карточку
uv run st-secretary preapp "C:\...\Предзаявки" --card "C:\...\Карточка.xlsx"
```

Пути к файлам — полные, в кавычках (в Проводнике: Shift + правая кнопка → «Копировать как путь»).

Результат обработки предзаявок — книга Excel:

- **Итог** — цифры и пошаговая инструкция переноса в СЕКРЕТАРЬ_ST;
- **Заявка для СЕКРЕТАРЬ** — очищенные данные в колонках листа «Заявка» СЕКРЕТАРЬ_ST, по командам;
- **Проверка** — все замечания: красные — ошибки, жёлтые — проверить, зелёные — исправлено системой
  (с колонками «почему», «что сделать», «было / стало» и номером строки в файле заявки);
- **Команды** — список команд с контактами представителей.

## Как запустить тесты

Нужен [uv](https://docs.astral.sh/uv/).

```bash
uv sync
uv run pytest
```

Сверка с реальными протоколами (файлы в репозиторий не входят) запускается, если указать папку с
эталонными данными:

```bash
ST_REF_DATA="путь/к/папке/с/данными" uv run pytest
uv run python tools/reconcile_psr2024.py --data "путь/к/папке/с/данными"
```
