### 1.2 Комиссия по допуску ✅

- [x] Решения: участник допускается сам, когда всё отмечено и замечаний нет; иначе — «допустить

- [x] Номера команд, взносы по карточке (оплачено, способ), итоги.
- [x] Перезаявки через форму заявки: что изменилось, время подачи, «не позднее 1 ч до старта»,
      «повторные не принимаются» (п. 8.5).
- [x] Протокол комиссии по форме Правил, ведомость взносов, документы участников — в Excel.
- [x] Проверка снаряжения: перечень из Положения (образец — «ПСР КРСК 2025»), личное / групповое /

- [x] Документы команды: сканы и фото в карточке команды, проверка «в одном окне» — документы слева,
