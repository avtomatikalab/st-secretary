Первый выпуск — для пробы на соревнованиях.

**Как установить (Windows).** Скачайте `st-secretary-0.1.0-windows.zip`, распакуйте архив («Извлечь все…») и дважды щёлкните «СТ-Секретарь.bat». Ничего устанавливать не нужно, интернет не нужен. Инструкция секретаря — файл `st-secretary-manual-0.1.0.pdf` (она же лежит в архиве и открывается кнопкой «Инструкция» в программе). Потренироваться можно на учебном соревновании — кнопка на главной странице.

**Что умеет**
- карточка соревнования, предварительные заявки с проверкой, комиссия по допуску;
- жеребьёвка и стартовые протоколы;
- протоколы этапов и результаты: ПСР, спелео, пешеходные, северная ходьба, горные; командные, личные и связки;
- телефоны судей этапов (баллы, время, отсечки) и табло по Wi-Fi;
- награждение, документы по итогам, договоры судей, акты, табель, сверка документов;
- судейская практика с баллами по приказу № 1101;
- резервные копии.

**Обновления.** С этой версии программа при запуске проверяет, нет ли новой версии, и предлагает обновиться одной кнопкой на главной странице. Соревнования, резервные копии и документы участников обновление не трогает; прежняя версия остаётся в папке `program.old`.

Данные соревнований хранятся только на вашем компьютере. Программа свободная (лицензия AGPL-3.0).
