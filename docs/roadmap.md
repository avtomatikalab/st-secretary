# План работ

## Этап 0 — фундамент ✅ (сентябрь 2026)

- [x] Справочники: ВРВС (сверен с реестром), разрядные нормы 2022–2025 и 2026–2029 (сверены
      с исходными таблицами), требования допуска ПСР, спелео, пешеходных.
- [x] Разряды: разбор любых написаний, старшинство.
- [x] Квалификационный ранг, условие ЕВСК о числе участников.
- [x] Нормативы: строка по классу и рангу, уровень соревнований, возраст, северная ходьба.
- [x] Места: равенство, неклассифицированные участники, «стартовавший раньше».
- [x] Профиль ПСР: баллы по этапам и турам, класс дистанции (табл. 3), ТШ этапа.
- [x] Профиль спелео: время, отсечки, баллы × 15/30 с, снятия.
- [x] Импорт СЕКРЕТАРЬ_ST и итоговых протоколов прошлых лет.
- [x] Сверка ПСР-2024: пересчёт совпал с итоговым протоколом у 10 команд из 11; найдены двойной
      учёт тура в рабочей книге, неверный код ВРВС в шапке, неподтверждаемый ранг.
- [x] Эталон ВС ПСР-2025: ранг 71,7 воспроизводится.

Ждёт данных от организаторов: формула ВШ между НВ и КВ, правила равенства в ПСР, методика
«% от победителя» для балльных дисциплин, перечень нарушений спелео (см. требования к эталонным
данным).

## Этап 1 — помощник секретаря поверх СЕКРЕТАРЬ_ST

- Карточка соревнования (реквизиты, ГСК, дисциплины, классы, редакция норм, методики).
- Приём и чистка предзаявок: слитные ФИО, даты в ФИО, несуществующие даты, пол по отчеству,
  варианты названий команд, проверки допуска → выгрузка в лист «Заявка» СЕКРЕТАРЬ_ST.
- Документы по шаблонам: протокол комиссии по допуску, дипломы, наклейки, справки о судействе,
  справка о составе СК, справка о субъектах, отчёт, договоры, акты, табель (суммы прописью,
  сверка дней).
- Сверка документов между собой (ФИО, даты, коды, суммы).

## Этап 2 — ПСР целиком в системе

- Ввод протоколов этапов секретарём (таблица), расчёт, предварительный протокол → час на протесты
  → официальный; ранг, нормативы, фактический класс.
- Онлайн-табло (облако) и местное табло (Wi-Fi ноутбука).

## Этап 3 — телефоны судей

- Электронный протокол этапа без связи: список по стартовому, нарушения по справочнику,
  таймеры КВ и отсечек, снятия с причиной; синхронизация через интернет / Wi-Fi / QR.
- Пилот на одном этапе ПСР или спелео, затем на всей дистанции.

## Этап 4 — остальные дисциплины и сервисы

- Профили горных, пешеходных дистанций, северной ходьбы.
- SPORTident: импорт SI Reader, затем прямое чтение станции.
- Учёт судейской практики (баллы на категорию), архив.
- ИИ-помощники: разбор заявок из почты, подсказка судье пункта таблицы штрафов.
- Донаты в облачной версии.
