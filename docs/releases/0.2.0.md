Теперь СТ-Секретарь работает на **Windows, macOS и Linux**.

Ничего устанавливать не нужно — ни Python, ни PowerShell, ни uv. Скачайте файл для своей системы (ниже, в
«Assets»), распакуйте и запустите.

**Какой файл скачать**
- Windows 10 и 11 — `st-secretary-windows.zip`: правой кнопкой → «Извлечь все…», в распакованной папке дважды
  щёлкните «СТ-Секретарь.bat».
- Mac с процессором Apple (M1 и новее) — `st-secretary-macos-arm64.tar.gz`.
- Mac с процессором Intel — `st-secretary-macos-x86_64.tar.gz`.
- Linux (x86_64) — `st-secretary-linux-x86_64.tar.gz`.

«Source code (zip)» — исходный код для разработчиков, секретарям и судьям он не нужен.

Какой у вас Mac — яблоко в левом верхнем углу экрана → «Об этом Mac»: «Чип Apple M…» или «Процессор Intel».

**Mac и Linux — проще всего одной командой.** Откройте Терминал, вставьте строку и нажмите Enter:

```
curl -fsSL https://raw.githubusercontent.com/avtomatikalab/st-secretary/main/tools/install.sh | sh
```

Программа сама выберет версию для вашего компьютера, встанет в папку «СТ-Секретарь» в домашней папке, сделает ярлык (Mac — на Рабочем столе, Linux — в меню программ) и запустится. Если вместо этого скачать архив для Mac через браузер, при первом запуске «СТ-Секретарь.command» macOS скажет, что не может проверить разработчика: «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть» (один раз).

**Обновление.** У кого стоит 0.1.0 для Windows, программа сама предложит обновиться на главной странице — одной кнопкой. Соревнования и резервные копии остаются на месте.

Инструкция секретаря — `st-secretary-manual.pdf` (в ней добавлено, как запускать на Mac и в Linux). Данные соревнований хранятся только на вашем компьютере. Программа свободная (лицензия AGPL-3.0).
